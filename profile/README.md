# HD Fowler Company

Internal applications and integrations built by the HD Fowler development team.

🌐 [hdfowler.com](https://www.hdfowler.com/)

## What we build

| Type | Stack | Used for |
| --- | --- | --- |
| **F7 Sites** | [Framework7](https://framework7.io/), JavaScript | Mobile-friendly web apps and portals for staff, drivers, and project teams |
| **SPFx Apps** | [SharePoint Framework](https://learn.microsoft.com/sharepoint/dev/spfx/sharepoint-framework-overview), TypeScript | Web parts and extensions for SharePoint Online and Microsoft 365 |
| **Azure Function Apps** | [Azure Functions](https://learn.microsoft.com/azure/azure-functions/), C# / TypeScript | Serverless APIs, scheduled jobs, and integrations that back our apps |
| **Acumatica Customizations** | [Acumatica](https://www.acumatica.com/) ERP, C# | Customizations and integrations for our ERP |

Also: on-prem APIs & tools.
